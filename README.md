# Game Show Game

Static, in-room Jeopardy-style game. Build a board, play in the room. No accounts, no backend.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Zustand for state
- Framer Motion for animations
- HashRouter (GitHub Pages friendly)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Pushing to `main` triggers GitHub Actions to build and deploy to GitHub Pages. Set the repo's Pages source to "GitHub Actions" once.
